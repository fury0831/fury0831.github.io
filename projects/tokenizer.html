Greedy matching is a local decision. Dynamic programming asks for the fewest tokens across the whole byte sequence.贪心匹配关注局部最长匹配，动态规划则寻找整个字节序列的最少 token 切分。

The question研究问题

With the vocabulary held fixed, how much can the encoding strategy change token count—and what does that cost in runtime?在词表固定时，编码策略能改变多少 token 数量？又要付出多少时间成本？

What the implementation does实现如何工作

01

Index bytes, not characters索引字节，而非字符

An immutable Trie indexes token byte sequences. Matching stays in byte space so multibyte text has an explicit representation.不可变 Trie 索引 token 的字节序列；匹配在字节空间中进行，明确处理多字节文本。

02

Choose locally or optimize globally局部选择，或全局优化

Greedy takes the longest available prefix. DP explores valid matches and minimizes token count for the fixed vocabulary.贪心选择最长可用前缀；DP 遍历有效匹配，在固定词表下最小化总 token 数。

03

Check semantics independently独立检查切分语义

Tests include an independent whole-vocabulary oracle. Decoding concatenates bytes before strict UTF-8 decoding.测试包含独立的全词表枚举 oracle；解码先拼接字节，再进行严格 UTF-8 解码。

Evidence in the project项目中的证据

  • 67 test methods are present in the supplied source; they were counted, not executed for this portfolio.提供的源码中有 67 个测试方法；本次仅统计数量，未执行测试。
  • A report records a fixed-vocabulary comparison and its runtime trade-off.报告记录了固定词表对照及其时间成本。
  • The custom encoder is separated from the reused course BPE trainer.自定义编码器与复用的课程 BPE 训练器分开组织。

What this does not establish这些证据还不能说明什么

  • Minimum token count does not imply better language-model quality or a better vocabulary.最少 token 数不代表更好的语言模型质量，也不代表更好的词表。
  • The smoke set is too small for a production performance claim.smoke 数据规模不足以支持生产性能结论。
  • Timings are historical report values; no fresh benchmark was run.耗时是报告中的历史数值，本次未重新测量。
