The arithmetic underneath底层的群运算

Point addition & doubling点加法与倍点

The addition routine handles O, inverse points, distinct-point addition, and doubling as separate cases. Modular inversion supplies the slope in the finite field.点加函数分别处理 O、互为负点、不同点相加与倍点。有限域中的斜率通过模逆计算。

02

Scalar multiplication标量乘

Binary double-and-add builds nP from the bits of n. The implementation also handles zero and negative scalars.二进制 double-and-add 根据 n 的二进制位构造 nP，也处理零标量和负标量。

03

Point enumeration & order点枚举与点阶

The code enumerates curve points, factors the group size by trial division, and reduces candidate orders by testing whether a multiple of Q equals O.代码枚举曲线点，用试除分解群大小，再检验 Q 的相应倍点是否等于 O，逐步缩小候选阶。

The modular square-root shortcut used for enumeration applies when p ≡ 3 (mod 4). It is not a general square-root routine for every odd prime.枚举中使用的模平方根捷径适用于 p ≡ 3 (mod 4)，并不支持所有奇素数。

From a character to a curve point从字符到曲线上的点

A fixed alphabet contains 67 characters: upper- and lower-case English letters, a space, digits, and four punctuation marks. Character i maps to (63 + i)P. The reverse procedure recalculates candidate multiples until one matches; collision and infinity checks help establish that this finite mapping can be reversed.固定字符表包含 67 个字符：英文大小写字母、空格、数字和四个标点。第 i 个字符映射为 (63 + i)P；反向过程逐个重新计算候选倍点并匹配，同时检查碰撞与无穷远点，以确认该有限映射可逆。

    Choose a character选择字符

    Find its zero-based position i in the supported alphabet.查找字符在支持的字符表中的零基位置 i。

  2. 02

    Form a scalar构造标量

    Offset the index: s = 63 + i.为索引加上偏移：s = 63 + i。

  3. 03

    Calculate the point计算曲线点

    Use double-and-add to obtain the message point M = sP.通过 double-and-add 得到消息点 M = sP。

  4. 04

    Recalculate candidate multiples until one matches the point, then return its character.逐个重新计算候选倍点，与目标点匹配后返回对应字符。

The security lesson: a public offset is reversible安全反思：公开偏移可以直接撤销

The original demonstration forms C = M + T, where T = nQ is public. Its recovery point is written as (k−n)Q with k equal to the order of Q. Since kQ = O, that recovery point is simply −T. Anyone can compute it from the public point.原演示使用 C = M + T，其中 T = nQ 公开。恢复点写为 (k−n)Q，k 是 Q 的阶。由于 kQ = O，恢复点其实就是 −T，任何人都能由公开点求出。

No secret is needed to undo the transformation撤销变换不需要秘密

In a curve group, the inverse of (x, y) is (x, −y mod p). Subtracting the published offset recovers M; neither n nor a discrete-logarithm solution is needed. The design therefore provides no confidentiality.曲线群中 (x, y) 的负点是 (x, −y mod p)。减去公开偏移即可恢复 M，不需要知道 n，也不需要求解离散对数。因此这一设计不提供保密性。

C − T = (M + T) − T = M

A fixed offset also sends repeated characters to repeated transformed points. The saved demonstration contains that repetition. No security or performance benchmark is claimed.固定偏移还会让重复字符产生重复的变换点，已有演示中可见这种重复。本项目不据此作安全性或性能保证。

Limits of the current notebook当前 notebook 的局限

  • Point enumeration and trial division are suited to small teaching parameters.点枚举与试除适用于小型教学参数。
  • The supported alphabet is fixed, and the mapping is not a general-purpose text encoding.字符表固定，映射不是通用文本编码。
  • The main demonstration has checks, but the attachment does not contain an independent test suite.主演示流程包含检查，但附件没有独立测试套件。
  • The saved record was inspected without executing the notebook. Successful recovery alone is not evidence of confidentiality.本次只检查保存记录，未执行 notebook。能够恢复消息本身并不能证明保密性。

Next improvements后续改进

  • Separate arithmetic, mapping, and demonstration code; document their input assumptions.拆分算术、映射与演示代码，明确各自的输入前提。
  • Test the identity, inverse, doubling, zero and negative scalars, invalid points, and unsupported characters.测试单位元、负点、倍点、零与负标量、非法点和不支持字符。
  • Align the field checks with the square-root method, or add a more general modular square-root algorithm.让域参数检查与平方根方法保持一致，或补充更通用的模平方根算法。
  • Study a standard encryption protocol separately, using its security assumptions and mature implementations as references.另行学习标准加密协议，以其安全假设和成熟实现为对照。

Related study drafts, kept distinct相关学习稿：明确区分版本

The local copy of the main notebook is byte-identical to the supplied attachment. Related notebooks explore real and finite-field point arithmetic, point enumeration and order, and an ElGamal-style decryption formula: C₁ = kG, C₂ = M + kY, followed by M = C₂ − dC₁ for Y = dG. This is a different construction from the public fixed offset discussed above.本地的主 notebook 与原附件逐字节相同。其他相关 notebook 探索了实数域与有限域点运算、点枚举和点阶，以及 ElGamal 式解密公式：C₁ = kG、C₂ = M + kY，在 Y = dG 时以 M = C₂ − dC₁ 恢复消息。这与前述公开固定偏移是不同方案。

The separate decryption draft has no saved execution counts or outputs, lacks initialized inputs in the notebook itself, and does not implement encryption or random k generation. It is an incomplete learning draft, not evidence of a tested secure encryption system.
