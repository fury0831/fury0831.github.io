Teaching RSA
factorization & decryption.教学 RSA
分解与解密。

An undergraduate exercise connecting integer factorization, modular inverses, and modular exponentiation into a readable decryption workflow.将整数分解、模逆与模幂串联为可理解的解密流程，是这项本科课程练习的目标。

The question研究问题

If a teaching RSA modulus can be factored into two distinct primes, how does that reveal the exponent needed to recover the encoded message?如果一个教学 RSA 模数能够分解为两个不同素数，如何据此求出恢复编码消息所需的指数？

Contribution & context贡献与背景

Undergraduate cryptography coursework. The notebook includes a section explicitly labelled “Starter algorithms”, references for factorization, and an integrated exercise workflow. These materials do not establish that every component was independently authored.本科密码学课程作业。Notebook 明确包含“Starter algorithms”章节、分解方法参考资料与整合后的练习流程，不能据此把每个组件都归为独立原创。

Source repository in preparation源码仓库整理中

From a public modulus to a teaching plaintext从公开模数到教学消息

Each input record contains a modulus n, a public exponent e, and a list of encrypted integers. The exercise factors the modulus, derives the private exponent, and converts the recovered integer codes back to text.每条输入记录包含模数 n、公开指数 e 和一个密文整数列表。练习先分解模数，再求私有指数，最后把恢复的整数编码转换为文本。

  1. 01

    Read a record读取一条记录

    Parse the teaching tuple (n, e, ciphertext). The original input file is separate from the notebook.解析教学记录 (n, e, ciphertext)；原输入文件与 notebook 分开存放。

  2. 02

    Factor n分解 n

    Use trial division for the smaller input, or Pollard rho to search for a nontrivial factor. Then set q = n / p.对较小输入使用试除，或用 Pollard rho 寻找非平凡因子，再令 q = n / p。

  3. 03

    Derive the exponent求解指数

    Assuming distinct primes, calculate φ(n) = (p−1)(q−1) and the inverse d = e⁻¹ mod φ(n).在两个因子为不同素数的假设下，计算 φ(n) = (p−1)(q−1) 与模逆 d = e⁻¹ mod φ(n)。

  4. 04

    Recover each code恢复各个编码

    Compute m = cᵈ mod n by repeated squaring, then interpret the integer codes using the exercise’s character representation.通过重复平方计算 m = cᵈ mod n，再按练习中的字符表示解释整数编码。

This is a static explanation of the notebook. No decryption service runs on this page, and no course code was executed to prepare it.这是对 notebook 流程的静态解释。本页不运行解密服务，整理页面时也未执行课程代码。

Four algorithms working together四类算法如何配合

01

Trial division试除

Test candidate divisors to find a factor. The notebook routes inputs below 10¹⁰ to this method; that threshold is an implementation choice, not a measured performance boundary.逐个检验候选除数以寻找因子。Notebook 对小于 10¹⁰ 的输入采用此方法；这个阈值是实现选择，不是测量得到的性能分界。

02

Pollard rhoPollard rho

Iterate x² + c modulo n with slow and fast pointers. A nontrivial gcd of their difference and n yields a factor; the notebook changes c after a failed attempt.在模 n 下迭代 x² + c，使用快慢指针；两者差值与 n 的非平凡最大公因数给出因子。Notebook 在失败后调整 c 再试。

03

Extended Euclidean algorithm扩展欧几里得算法

Track Bézout coefficients while computing a gcd. When gcd(e, φ(n)) = 1, the coefficient of e gives its modular inverse and hence d.计算最大公因数的同时跟踪 Bézout 系数。当 gcd(e, φ(n)) = 1 时，e 的系数给出模逆，从而得到 d。

04

Fast modular exponentiation快速模幂

Repeated squaring evaluates cᵈ modulo n without constructing the full integer power. It is used in the final recovery step.重复平方在模 n 下计算 cᵈ，无需构造完整的大整数幂，用于最后的恢复步骤。

Limits of the exercise练习的局限

  • The φ(n) formula assumes two distinct prime factors; that structure is not fully validated in the workflow.φ(n) 的公式依赖两个不同素数的结构，流程尚未充分验证这一前提。
  • The Pollard rho loop has no explicit iteration budget or timeout, and unsuccessful modular inversion needs clearer handling.Pollard rho 循环没有明确的迭代预算或超时；模逆不存在的情况也需要更清晰的处理。
  • Character-by-character recovery and small exercise inputs do not establish the ability to break modern RSA or implement a secure protocol.逐字符恢复和小型练习输入，不能证明能够攻破现代 RSA，也不构成安全协议实现。
